## 1. 职责边界

| 问题 | 归属 |
|---|---|
| 两个物体是否重叠 / 相交？接触点在哪？法线朝哪？ | **本章**：碰撞检测 |
| 重叠后怎么弹开、怎么传递动量、摩擦多少？ | `12-物理引擎.md`：运动响应 |
| 鼠标点到了哪个物体？ | 第 03 章 `Ray` + `Bounds` 拾取（一次性查询，不是持续重叠） |
| UI 按钮点到了吗？ | 第 08 章 UI 命中（屏幕空间，优先级高于世界拾取） |

碰撞体是挂在 GameObject 上的组件，跟 Transform 走；两个碰撞体必须分别属于两个节点（第 02 章同类组件唯一），碰撞关系是「组件对组件」，事件投递给各自宿主节点上的 Behaviour。

## 2. 碰撞体类型【已落盘（Box/Sphere/Capsule/Mesh 退化盒）；偏离说明见下】

| 组件 | 形状参数 | 窄相算法 | 状态 |
|---|---|---|---|
| `BoxCollider` | `Float32_3 center / size`（local） | AABB 重叠 + 最小穿透轴（`computeBoxContact`） | ✅ |
| `SphereCollider` | `Float32_3 center`、`Float32 radius`（local） | 球心距（`computeSphereContact`）；世界半径 = radius × max(scale) | ✅ |
| `CapsuleCollider` | `center`、`radius`、`height`（总高含两端半球；线段沿节点 local +Y） | 线段最近点（cap/sphere、Ericson 5.1.4 cap/cap）+ 三候选近似（cap/box） | ✅ |
| `MeshCollider` | 继承 `BoxCollider`（size=网格近似包围盒）+ `convex` 标记 + **v1：`setMeshVertices(List<Float32_3>)` 凸点集登记 + `meshIntersects(other)` GJK 查询** | **v1 GJK 精化**：盒-盒窄相命中后双方均有点集 → C `sle_gjk_intersect` 复核（false 撤销误报对）；接触法线/穿透仍取盒路径近似（EPA 远期）；无点集一方走退化盒 | ✅（退化盒 + GJK 精化） |
| `PlaneCollider` | `Plane` 实例 | 平面有符号距离（第 03 章 `distanceToPoint` 已落盘） | 设计稿 |

**与设计稿的偏离（doc/10 §6 跨模块缺陷规避，已实证）**：不做 `Collider` 公共基类——Behaviour 子类实例的跨模块数值字段读不可靠（Int32 读垃圾 / `== 常量` 失效），`isTrigger` 直接声明在各具体类；多态窄相由 `CollisionSystem` 的 kind 分派替代；事件钩子参数统一 `Behaviour` 类型（混合形状对兼容；按名派发不校验参数类型）。`overlaps/computeContact` 契约由各具体类以 `computeBoxContact/computeSphereContact` 形态提供。

**法线双重约定（新增形状对接必读）**：配对级约定 `info.normal` = B→A（A=配对第 i 个，doc/12 物理求解依赖）；各 compute 方法约定 = other→self。两者只在「方法在 A 侧调用」时一致——形状 X 在 B 侧被委托计算时（如 box(A)/capsule(B) 委托 `capsule.computeBoxContact(box)`），方法返回 A→B，**分派层必须取反**（P3 补全实证：漏取反时物理把刚体往接触面里压，胶囊落地变下陷）。新碰撞体接入时按「自身在 A 侧的三分支 + 在 B 侧的三分支取反」核对六格。

已落盘 API：

```sl
public class ContactInfo        # 普通类（非继承链，字段跨模块读可靠）
{
    public Float32_3 point         # 接触点（世界空间，两中心中点近似）
    public Float32_3 normal        # 法线（从 other 指向自身；接收方视角）
    public Float32   penetration   # 穿透深度 >= 0（最小穿透轴 / 半径和-距离）
}

public class BoxCollider extends Behaviour
{
    public bool isTrigger
    public Float32_3 center / size                 # local
    public Bounds worldBounds                      # refreshWorldBounds() 刷新
    void refreshWorldBounds()                      # 8 顶点 × worldMatrix → fromPoints
    bool computeBoxContact( BoxCollider other, ContactInfo info )
    bool computeSphereContact( Float32_3 center, Float32 radius, ContactInfo info )
    # 事件钩子（CallHook1/2 按名派发到最派生 override）：
    onCollisionEnter/Stay( Behaviour other, ContactInfo info )
    onCollisionExit( Behaviour other )
    onTriggerEnter/Stay/Exit( Behaviour other )
}

public class SphereCollider extends Behaviour     # 同构（worldCenter/worldRadius）

public class CapsuleCollider extends Behaviour    # P3 补全（2026-11-16）
{
    public bool isTrigger
    public Float32_3 center                        # local 胶囊中心
    public Float32 radius / height                 # height=总高，自动钳 >= 2*radius
    public Float32_3 worldA / worldB               # 世界线段两端点（local +Y 轴向）
    public Float32 worldRadius / Bounds worldBounds
    void refreshWorldBounds()
    bool computeSphereContact( SphereCollider other, ContactInfo info )   # 线段最近点 + 球判定
    bool computeCapsuleContact( CapsuleCollider other, ContactInfo info ) # Ericson 5.1.4 线段-线段
    bool computeBoxContact( BoxCollider box, ContactInfo info )           # 三候选近似（见下）
    # 事件钩子与 Box/Sphere 同款六件
}

public class MeshCollider extends BoxCollider    # P3 补全 v0.1（退化盒）+ v1 GJK 精化（2026-11-17）
{
    public bool convex = true                    # 凸包标记（GJK 语义前提；凹网格自行拆凸块）
    public void setMeshVertices( List<Float32_3> localVerts )  # 凸点集登记（Memory 块缓存）
    public Int32 meshVertCount()
    public bool meshIntersects( MeshCollider other )           # GJK 布尔查询（C 核心）
    public bool meshContact( MeshCollider other, ContactInfo info )  # GJK+MTV：覆写 normal/penetration/point
    # size/center/isTrigger/worldBounds/事件钩子全继承 BoxCollider；
    # gather 收 kind=0 盒路径，窄相 `as BoxCollider` 多态兼容——
    # CollisionSystem 无需新 kind；盒-盒命中后双方有点集 → GJK 复核
}
```

**MeshCollider 退化盒要点**：`MeshCollider extends BoxCollider` 是具体类继承具体类（is-a 复用），不违反「不做 Collider 公共基类」偏离；`size` 即「网格近似包围盒尺寸」，由使用方手动设——碰撞精度与盒一致。

**MeshCollider GJK + MTV 精化（v1，2026-11-17）**：`setMeshVertices(localVerts)` 一次性把凸点集组进 Memory 块（float3 紧凑；与碰撞体同生命周期，无 dispose 钩子）；`meshIntersects(other)` 布尔判定、`meshContact(other, info)` 相交时把 ContactInfo 的 **normal（B→A）与 penetration 覆写为 C `sle_gjk_mtv` 的 26 方向采样 MTV 结果**（轴对齐形状精确、旋转形状保守近似；point 取双方包围盒中心中点）——每次查询经 C `sle_points_transform`（行主序 4x4 × 点集）刷新世界顶点，**计算全在 C**（复用专项约定）。CollisionSystem 盒-盒窄相：`computeBoxContact` 命中后若双方均为 MeshCollider 且点集非空 → `meshContact` 复核，false 撤销该对（消除包围盒误报）、true 覆写接触。mesh-mesh 物理链路已通（`SimGjkTest` G6：mesh 刚体落 mesh 地面 y≈1.5 静置）。用法：

```sl
MeshCollider mc = MeshCollider()
mc.size = Float32_3( 4, 4, 4 )            # 包围盒（宽相/退化路径用）
mc.setMeshVertices( convexVerts )         # 凸点集（GJK 精化用；凹网格自行拆凸块）
```

**胶囊 vs 盒的三候选近似**：胶囊线段对盒心的投影点 + 两端帽心，各做一次「盒.closestPoint 球判定」，取穿透最大者。已知偏差：细长盒角落处接触点略有偏移；精确 GJK 与 MeshCollider 同族远期。物理侧无需感知——接触经 `contactInfo(i)` 通用接口进 `PhysicsSystem.solveContacts`（胶囊刚体落地/休眠与盒/球同路径，`SimCollisionTest` CC5 已验证）。

`worldBounds` 是**轴对齐**盒：节点旋转后由 `refreshWorldBounds()` 用变换后的 8 顶点重新 `Bounds.fromPoints()` 生成世界 AABB，不能直接拿 local `size` 加世界位置（第 03 章 §5 已说明；`SimCollisionTest` C9 已验证）。

## 3. 宽相与窄相【已落盘（CollisionSystem.step）】

### 3.1 宽相（Broadphase）【已落盘（AABB）】

先排除明显不可能相交的对象对，避免 O(n²) 全配对：

1. **AABB 快速判定**：`worldBounds.intersects(other.worldBounds)`（已落盘）为 false 直接跳过；
2. **空间网格**：把世界划分成固定大小格子，碰撞体登记覆盖的格子，只检测同格对象（设计稿）；
3. **动态对象稀疏、静态对象多**时，静态碰撞体可缓存 AABB，只在 Transform 标脏时刷新。

### 3.2 窄相（Narrowphase）【已落盘（kind 分派）】

宽相通过后，按形状对计算精确接触（CollisionSystem 内 kind 分派，不走多态——doc/10 §6）：

| 形状对 | 判定依据 | 状态 |
|---|---|---|
| Box / Box | AABB 重叠 + 最小穿透轴 | ✅ |
| Sphere / Sphere | 中心距 ≤ 半径和 | ✅ |
| Sphere / Box | 球心到 AABB 的 `closestPoint()`（已落盘） | ✅ |
| Capsule / Sphere | 线段最近点 + 球判定 | ✅ |
| Capsule / Capsule | 线段-线段最近点（Ericson 5.1.4） | ✅ |
| Capsule / Box | 三候选近似（投影点 + 两帽心取穿透最大） | ✅ |
| Mesh / Mesh（双方有点集） | **GJK+MTV 精化**：盒窄相命中后 C `sle_gjk_intersect` 复核 + `sle_gjk_mtv`（26 方向采样）覆写 normal/penetration；false 撤销误报对 | ✅ v1 |
| Mesh / 任意（无点集方） | **退化盒**：MeshCollider 继承 BoxCollider，按盒对走（含 Ray/Mesh 拾取） | ✅ |
| Ray / Collider | `Ray.intersectBounds()` / `Plane.raycast()`（已落盘，拾取直接查询） | ✅ |

### 3.3 碰撞矩阵【已落盘（对称 AND 语义）】

按 layer 决定「谁和谁检测」，与渲染的 `cullMask` 是**两套独立掩码**：

```sl
# 已落盘：第 i 位为 1 表示该 layer 允许与 layer i 碰撞；对称 AND——
# 双方矩阵都允许才碰撞（setLayerMask(1, 0) 即可让 layer1 与任何层断开）
CollisionSystem cs = CollisionSystem()
cs.setLayerMask( 1, 0 )          # layer1 不与任何层碰
cs.getLayerMask( layer )         # 读回
```

常见配置：玩家 ↔ 敌人 / 地形 / 触发器；触发器 ↔ 玩家；UI layer 不参与世界碰撞。
注意：矩阵用 `Array<Int32>` 存储（List 下标写跨模块失效，doc/10 §6）。

## 4. 触发器与事件【已落盘（CollisionSystem.step + CallHook1/2 派发）】

### 4.1 触发器 vs 实体碰撞体

| 类型 | `isTrigger` | 行为 |
|---|---|---|
| 实体碰撞体 | false | 检测重叠并产生 `ContactInfo`，交给第 12 章求解弹开 |
| 触发器 | true | 只报告进入 / 停留 / 离开，**不产生接触法线与穿透深度**，不阻挡移动 |

触发器体积常用 `BoxCollider` + `isTrigger = true`，用来做拾取区、伤害区、检查点。

### 4.2 钩子（经 C 侧按名派发到最派生 override——跨模块 CallVirt 断点规避）

```sl
# 探针形态：继承具体碰撞体并 override（SimCollisionTest HitBox/HitSphere 同款）
public class HitBox extends BoxCollider
{
    public Int32 enterCount = 0

    public override void onCollisionEnter( Behaviour other, ContactInfo info )
    {
        this.enterCount = this.enterCount + 1
        # info.normal 从 other 指向自身；触发器事件无 info（§6.4）
    }

    public override void onTriggerEnter( Behaviour other )
    {
        # other.owner.tag == "Pickup" → other.owner.destroy()
    }
}
```

事件派发：双方各收一次（A 视角 other=B，B 视角 other=A；normal 各自取向）。P3 简化：事件只投给宿主的 Collider 组件自身（多 Behaviour 广播随 P5）。

### 4.3 事件投递时机【已落盘（Application 固定步自动 step）】

```
app.collisionSystem = CollisionSystem()   # 赋实例启用（默认 null 禁用）
每个 fixedUpdate 步末自动调用 step(activeScene)：
  1. 收集 Collider（显式栈遍历，键一次读全平行数组——doc/10 §6）
  2. 宽相配对 → 窄相求 ContactInfo
  3. 与持续接触表比对：
       新出现 → Enter（登记配对）
       持续   → Stay
       消失   → Exit（移除配对）
  4. 实体接触送第 12 章求解；触发器只发事件（disableTriggerEvents 可关）
```

Enter/Stay/Exit 的判定必须在固定步长里做，否则帧率变化会导致事件漏发或重复（`SimCollisionTest` C7 验证 paused 冻结）。

## 5. 示例：拾取区【已落盘 API 形态】

```sl
import SimGameEngine;
import Std;
import Math;

# 触发器（拾取区）
GameObject zone = scene.createObject( "PickupZone" )
zone.layer = 3
HitBox trigger = HitBox()

zone.addComponent( trigger )            # 默认 size 1×1×1 @ 节点原点

# 玩家（实体碰撞体）进入时 HitBox.onTriggerEnter 按名派发收到事件
```

## 6. 已知坑与注意

1. **别把渲染 layer 掩码当碰撞矩阵用**：`cullMask` 决定「画不画」，碰撞矩阵决定「碰不碰」，两者语义独立，可以不同值。
2. **旋转节点的 AABB 要重算**：`Bounds` 是轴对齐的；`refreshWorldBounds()` 已按变换后 8 顶点重算，不要绕过引擎直接用 local 尺寸判定。
3. **穿透过深时接触法线不稳定**：最小穿透轴在接近立方体对角时会跳变；第 12 章的 CCD 与位置修正可缓解。
4. **触发器不提供法线**：不要从 `onTriggerEnter` 里读 `ContactInfo.normal` 做反弹；需要反弹就把碰撞体设为非 trigger（P3 触发器事件本就不带 info）。
5. **事件横穿固定步长与渲染帧**：`fixedUpdate` 一帧可能跑多次（第 09 章累加器），Stay 事件可能一帧内出现多次；脚本要做幂等处理。
6. **不做 Collider 基类**（doc/10 §6）：Behaviour 子类跨模块数值字段读不可靠——`isTrigger` 在各具体类声明、窄相 kind 分派、事件参数用 `Behaviour` 类型；消费方拿碰撞体用具体类型探针（`getComponent<BoxCollider>()` 可命中子类，C 侧按 cast 语义匹配）。
7. **碰撞矩阵用对称 AND 语义**：双方矩阵都允许才碰撞；`setLayerMask(1, 0)` 即让 layer1 与任何层断开。矩阵是 `Array<Int32>`（List 下标写跨模块失效）。
