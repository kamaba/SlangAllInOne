# 原生 C 包装层设计（`cvm_webui_lib`）

> 本文定义 `cvm_webui_lib`（产 `webui_lib.dll`）的内部设计：如何把 webui 扁平化为
> SLang 可直调的 C ABI、回调桥 trampoline 池、事件读取/返回转发、`webui_script` 输出
> 缓冲区封装、内存与错误约定。上层接口见 `02` / `03`。
>
> 模板参照：`SlangAllInOne/SLangCore/Lib/SLang/Mysql/cvm_sl_mysql_lib/`
> （`sl_mysql_lib.c` + `vm_sl_mysql.h`，扁平 C ABI 包装 + 命名前缀约定）。

---

## 1. 文件结构

```

```

---

## 2. 导出命名约定

- 前缀 `webui_` 保留给 vendored webui 自身；**本包装层统一前缀 `webui_*` 再追加 `_sl`**
  （SimpleLanguage）以区分，例如 `webui_new_window_sl`、`webui_bind_sl`。
- `SLM_API` 风格的导出宏：Windows `__declspec(dllexport)`，其它为空（同 `vm_sl_mysql.h`）。
- **所有导出函数参数 ≤6、纯标量**（bool / 整数 / `const char*` / `ptr`），与 SLang
  `sl_ffi_call` 的 x64 ABI 分类（INT 类含 ptr/utf8，DBL 类 f32/f64）对齐。
- `const char*` 返回值：一律指向 webui 内部缓冲或本库线程局部缓冲，**调用方（VM）不得
  free**；VM 在返回瞬间拷入自身 string（与 `slm_error` 同约定）。

## 3. 回调桥（核心）

### 3.1 数据结构

```c
/* bind_id -> SLang 回调节流点地址（createCallback 生成，签名 void(*)(int64_t)） */
typedef struct {
    size_t   bind_id;
    int64_t  sl_cb;          /* C function pointer: void(*)(int64_t) */
} sl_webui_binding_t;

static sl_webui_binding_t g_bindings[SL_WEBUI_BIND_MAX];  /* 默认 1024，可动态扩容 */
static int                g_bind_count = 0;
```

### 3.2 单一 trampoline（读 bind_id 查表）

```c
/* webui 调用的原生回调：统一入口 */
static void sl_webui_trampoline(webui_event_t* e) {
    int64_t sl_cb = sl_webui_find_cb(e->bind_id);   /* 查 g_bindings */
    if (sl_cb == 0) return;                          /* 未绑定，安全跳过 */
    /* 重入 SLang VM：把事件指针作为 int64 参数传入 createCallback 节流点 */
    ((void (*)(int64_t))sl_cb)((int64_t)(uintptr_t)e);
}
```

> 关键：**不**为每个 bind 生成独立函数（规避运行时代码生成 / 可执行内存平台差异）。
> 所有 bind 共用 `sl_webui_trampoline`，靠 `e->bind_id` 区分目标 SL 方法。

### 3.3 `webui_bind_sl`（注册）

```c
/* SLang: WebUI.libBind(window, element, cbPtr) */
SLW_API int64_t webui_bind_sl(int64_t window, const char* element, int64_t sl_cb) {
    size_t id = webui_bind((size_t)window, element, sl_webui_trampoline);
    if (id == 0) return 0;                            /* webui 失败 */
    sl_webui_add_binding(id, sl_cb);                   /* 写入 g_bindings[id] */
    return (int64_t)id;
}
```

- `webui_bind` 返回 0 表示失败（如 window 非法）；成功返回递增 bind_id。
- `sl_webui_add_binding` 写 `g_bindings`（按 bind_id 索引，超容则动态 realloc）。
- SLang 处理函数签名 `static void onEvent(Int64 e)`，对应 createCallback sig `"ptr->void"`
  （事件指针进、void 出），与 trampoline 调用约定一致。

### 3.4 清理

- `webui_destroy_sl(window)` / `webui_exit_sl()` 调用 webui 原生关闭后，遍历
  `g_bindings` 清空（SLang 侧 `createCallback` 的槽位由 `FFI.StaticLibrary.freeCallback`
  释放，或由 VM 退出统一回收，见 `ffi.md` §8.11）。

## 4. 事件读取 / 返回（直接转发）

SLang 处理函数内需要读取事件参数、回写返回值。这些 webui API 参数 ≤6、纯标量，
**直接转发**即可（无需 trampoline）：

```c
SLW_API int64_t webui_get_count_sl   (int64_t e) { return (int64_t)webui_get_count((webui_event_t*)(uintptr_t)e); }
SLW_API int64_t webui_get_int_at_sl  (int64_t e, int64_t i) { return (int64_t)webui_get_int_at((webui_event_t*)(uintptr_t)e, (size_t)i); }
SLW_API double  webui_get_float_at_sl(int64_t e, int64_t i) { return webui_get_float_at((webui_event_t*)(uintptr_t)e, (size_t)i); }
SLW_API const char* webui_get_string_at_sl(int64_t e, int64_t i) { return webui_get_string_at((webui_event_t*)(uintptr_t)e, (size_t)i); }
SLW_API int32_t webui_get_bool_at_sl (int64_t e, int64_t i) { return webui_get_bool_at((webui_event_t*)(uintptr_t)e, (size_t)i) ? 1 : 0; }

SLW_API void webui_return_int_sl   (int64_t e, int64_t n) { webui_return_int((webui_event_t*)(uintptr_t)e, (long long)n); }
SLW_API void webui_return_float_sl (int64_t e, double f)  { webui_return_float((webui_event_t*)(uintptr_t)e, f); }
SLW_API void webui_return_string_sl(int64_t e, const char* s) { webui_return_string((webui_event_t*)(uintptr_t)e, s); }
SLW_API void webui_return_bool_sl  (int64_t e, int32_t b) { webui_return_bool((webui_event_t*)(uintptr_t)e, b != 0); }
```

- 事件指针在回调期间有效；`get_string_at` 返回的 `const char*` 由 webui 持有，VM 读后即
  拷，安全。
- 返回函数由 webui 内部拷贝，SLang 侧 utf8 临时缓冲调用后失效，安全。

## 5. `webui_script` 输出缓冲区封装

webui 原生 `webui_script(size_t, const char* js, size_t timeout, char* buf, size_t len)`
的 `buf/len` 是输出缓冲区，SLang FFI 无法表达。本层封装为 `->string`：

```c
/* SLang: WebUI.libScript(window, js, timeoutSec) -> string */
#define SL_WEBUI_SCRIPT_BUF 65536
SLW_API const char* webui_script_sl(int64_t window, const char* js, int64_t timeout) {
    static char buf[SL_WEBUI_SCRIPT_BUF];          /* 线程局部更佳，见下方说明 */
    bool ok = webui_script((size_t)window, js, (size_t)timeout, buf, sizeof(buf));
    if (!ok) return "";                            /* 执行错误返回空串 */
    return buf;                                    /* VM 立即拷走，安全 */
}
```

> ⚠️ 线程安全：`ui_event_blocking=true`（见 `02` §4）下事件串行，静态缓冲够用；若后续
> 放开多线程，需改为 `__thread` / 每调用 `webui_malloc` 缓冲并由调用方感知。P1 采用
> 线程局部缓冲（`_Thread_local`）消除隐患。

## 7. 错误与诊断

- `webui_get_last_error_number()` / `webui_get_last_error_message()` 经 `_sl` 封装暴露，
  SLang 可在 `WebUI.init()` 后或异常分支读取；
- DLL 缺失时所有 `_sl` 函数走 SLang 侧 `@DllStaticImport` 兜底函数体（返回零值/空串），
  不会引发 VM 崩溃。

## 8. 与 Mysql 包装层的差异小结

| 维度 | `cvm_sl_mysql_lib` | `cvm_webui_lib` |
|---|---|---|
| 底层库 | mysqlclient.lib（GPL-2.0，静链） | webui.c（MIT，内嵌源码） |
| 句柄 | MYSQL/MYSQL_RES → Int64 | size_t 窗口号 → Int64 |
| 回调 | 无 | **有**：trampoline 池 + bind_id 映射 |
| 输出缓冲 | 无 | `webui_script` → string 封装 |
| 线程 | 调用方自管 | 默认 `ui_event_blocking=true` 串行 |

## 9. 合规与 vendoring

- webui 头/源 **原样 vendored**（保留 MIT 版权头与 `LICENSE`），仅新增 `cvm_webui.*`
  自有文件；
- MIT 允许修改与再分发，**可随 SLang 官方发布包分发**（无 Mysql 的 GPL 红线）；
- vendored 版本钉死 `2.5.0-beta.4`（见 `01` §3），升级需复核 API 漂移（见 `07`）。
