# Encoding/Sha256.sl

> 源文件：`Encoding/Sha256.sl`

## class `Sha256`

- **说明**：SLang 标准库类型 Sha256（详见源文件）。

| 类型 | 签名 | 说明 |
|------|------|------|
| 方法 | `ByteBuffer digest(ByteBuffer src)` | ── 摘要 ── 计算 src 可读区的 SHA-256 摘要，返回新 32 字节缓冲；src 索引不变 |
| 方法 | `ByteBuffer digest(string src)` | 计算 UTF-8 文本字节的 SHA-256 摘要，返回新缓冲（中间缓冲即时释放） |
| 方法 | `string digestHex(ByteBuffer src)` | 摘要并输出为 64 字符小写十六进制串 |
| 方法 | `string digestHex(string src)` | 文本到文本高频快捷入口：UTF-8 文本 -&gt; 小写十六进制摘要 |
| 方法 | `ByteBuffer hmac(ByteBuffer key, ByteBuffer src)` | ── HMAC-SHA256 ── 计算消息可读区在密钥下的 HMAC-SHA256，返回新 32 字节缓冲； key/src 索引均不变；键/消息空可读区均合法 |
| 方法 | `ByteBuffer hmac(string key, string src)` | 文本便捷形态：UTF-8 密钥 + UTF-8 消息 -&gt; 新缓冲（中间缓冲即时释放） |
| 方法 | `string hmacHex(ByteBuffer key, ByteBuffer src)` | HMAC 并输出为 64 字符小写十六进制串 |
| 方法 | `string hmacHex(string key, string src)` | 文本到文本高频快捷入口：UTF-8 密钥 + UTF-8 消息 -&gt; 小写十六进制 HMAC |
