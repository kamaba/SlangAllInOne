# 09 · 构建管线集成

> 把 **`.sl` 编译进 Unity 包** 的流程：Unity 构建事件触发 `slang compile --format binary+json`，
> 产物放 `StreamingAssets` 或 Addressables，运行期由 `SlangModuleLoader`（`04`）装载。

---

## 1. 编译入口（复用 Front CLI）

`csimple_lang/md/cli.md` / Front：`slang compile --format binary+json` 产出 `*.module.slb` + `*.module.json` 调试副本。
- R15：热更/运行一律 `binary+json`（slb 主产物 + json 副本）。
- 内存链路（`--export-mode memory`）不落盘、SLB 不压缩内存直传（`SLB_DESIGN.md` §7.1），适合 Editor 内零落盘热写（`04` §2.2）。

---

## 2. Unity 构建事件钩子

| 钩子 | 用途 |
|------|------|
| `IPreprocessBuildWithReport` | 构建前：编译所有 `.sl` → slb，校验 Front 可用 |
| `IPostprocessBuildWithReport` | 构建后：把 slb 拷进 `StreamingAssets/Slang/` |
| `IProcessSceneWithReport` | 场景保存时预编译（可选） |
| `AssetPostprocessor` | `.sl` 导入即编译（Editor 热更，`04` §3） |

建议：把 `slang` 可执行（宿主 `SlangAllInOne`，`AGENTS.md` §1）作为 Unity 工程的外部工具，
构建事件用 `Process.Start` 调它；或预编译好 slb 随资源提交，构建只拷贝。

---

## 3. 资源流布局

```
Assets/
  StreamingAssets/
    Slang/
      Core.module.slb        (引用库，R15 官方库目录约定)
      Std.module.slb
      MyHot.module.slb       (热更模块)
  Plugins/
    x86_64/csimple_lang.dll  (原生插件，见 02)
    Android/libs/arm64-v8a/libcsimple_lang.so
    ...
  SlangUnity/               (桥接层 + 绑定层 C# 源码，见 03/05)
    SlangUnityBridge.cs
    SlangModuleLoader.cs
    SlangHostCallbacks.cs
    SlangLifecycle.cs
```

- 运行期 `base_dir`（`cli_run_module_in_memory` 参数）通常传 `Application.streamingAssetsPath + "/Slang"`，
  使 `moduleReferences` / 插件 lib 相对它解析（`cli.md` 宿主 API 段）。
- **Android 注意**：`StreamingAssets` 在 apk 内是压缩包，运行期需先拷到 `Application.persistentDataPath` 再装载（Unity 通病）。iOS 可直接读。

---

## 4. Addressables（可选进阶）

- 若热更模块要**远程下发**，把 slb 作为 Addressables 远程资源，下载到 `persistentDataPath` 后由 `04` §3 远程下载链路装载。
- 引用库（Core/Std）可随包内置（`StreamingAssets`），热更模块远程拉取，减小首包。

---

## 5. 真机热更包下载

```
服务器 新 MyHot.module.slb
   → Unity WebRequest 下载到 persistentDataPath/Slang/
   → FileSystemWatcher / 完成回调 → 主线程重装载（04 §3）
```

> 安全：远程 slb 建议签名校验（见 `11` 沙箱/完整性），防止篡改热更代码。

---

## 6. 版本与回滚

- 每个 slb 带确定性 uuid（`SLB_DESIGN.md` §4.6）；下载前比对版本号（R17 四端版本）。
- 保留上一个可用 slb，装载失败自动回滚（loader 捕获异常 → 还原旧域）。

---

- [ ] 远程下载 slb 后热更成功，失败能回滚。
