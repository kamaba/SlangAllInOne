# 07 · 调试与诊断

> 复用 C VM 的 **SLDP 调试协议**（`csimple_lang/md/design/DEBUG_PROTOCOL_DESIGN.md`）
> 与 **日志机制**（`csimple_lang/md/cli.md` 文件日志段），为 Unity 开发者提供断点/单步/变量树/表达式求值。

---

## 1. SLDP 调试器接入（核心）

C VM 已实现 SLDP v1.1（D-P1~D-P4a）：断点 / 单步 / 变量树 / 表达式求值，传输为
**NDJSON over TCP**，单连接，监听 `127.0.0.1:<port>`。

启动方式（`csimple_lang/md/cli.md`）：
```
--debug-server=<port>     等号式传端口（1..65535）
```
- 会话开启即**自动禁 JIT**（见 `08` §4，与调试器语义一致）。
- stderr 打印 `listening/paused at/continued` 佐证日志。

### Unity 侧接入方案
1. **Editor 扩展**：写一个 Unity Editor 窗口 / 外部调试客户端（Node/Python），连 `127.0.0.1:<port>`。
2. **`slang run` 透传**：宿主 `slang run` 已同名透传 `--debug-server`（见 AGENTS R20），Unity 桥接层在调 `cli_run_module_in_memory` 前，经 flags 或 host 注入开启调试会话（注意：内存 API 无 argv，需在 host 层加一个 `SLVmExt` 级调试 setter，对齐 `JIT_DESIGN` §6.1 规则 4 的「dll 宿主无 CLI 通道」处理）。
3. **冒烟**：复用 `SlangAllInOne/SLangCore/test/Other/DebugSmoke/smoke.js` 作为协议连通性验证。

## 2. 日志桥接

C VM 结构化日志（`csimple_lang/md/cli.md`）：
- 默认关闭；设 **`SL_VM_LOG=on`**（或 `1`/`true`，大小写不敏感）开启文件日志 `build/logs/VM.txt`。
- stdout 与调试器输出不受影响。

Unity 侧：
- `SlangLogger`（`03` §4）把 VM 输出重定向到 `Debug.Log` / `Debug.LogWarning` / `Debug.LogError`。
- 开发期可同时开 `SL_VM_LOG=on` 落盘，便于离线排查。

---

## 3. `--debug` vs 文件日志

| 模式 | 行为 | Unity 用途 |
|------|------|-----------|
| `SLVM_MEM_FLAG_DEBUG`（`--debug`） | 逐指令追踪、槽位追踪（受 `SL_DEBUG` 宏约束） | 重度排障；自动关 JIT |
| `SL_VM_LOG=on` | 落 `VM.txt` | 运行期日志持久化 |
| 读取 JSON 通道 | `--debug` / `--force-json` 关 SLB 偏好 | 看明文载荷（排障） |

> R15：`--debug` / `--force-json` 会关闭「读取优先 SLB」偏好 → 排障时看 JSON 明文；
> 但热更常态仍走 SLB（见 `04`）。

## 4. 诊断命令（复用 CLI）

`csimple_lang/md/cli.md` 的只读诊断可直接用于 Unity 侧排查：
- `info <module>`：显示模块元数据（包数/方法数/入口），不执行。
- `plugin list/info <module>`：列出模块引用的插件与 capability。
Unity 桥接层可在 Editor 里暴露这些为按钮，快速核对「装载了哪个 slb / 引用是否齐全」。

---

## 5. 常见排障路径

| 现象 | 排查 |
|------|------|
| SL 逻辑不生效 | 热更没触发 / slb 陈旧（`04` §6）→ `info` 看装载包 mtime/uuid |
| 跨边界崩溃 | handle 表漏释放 / 对象已被 Unity 销毁（`05` §6） |
| iOS 崩在 JIT | 确认 `VM_JIT_ENABLE=OFF` + `SL_JIT=0`（`08`） |
| 中文乱码 | 确认 UTF-8 全程（`03` §2、R16） |
| 调试器连不上 | 端口占用 / 未开 `--debug-server`；确认 stderr `listening` 日志 |
