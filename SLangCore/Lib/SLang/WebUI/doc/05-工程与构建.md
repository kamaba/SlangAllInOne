# 工程与构建

> 本文定义 `SLangWebUI` 模块的工程文件（`WebUI.sp` / `WebUI.jsonc`）与原生库
> （`cvm_webui_lib`）的构建装配，完全对标 `SLang.Mysql`（`MysqlClient.sp` /
> `MysqlClient.jsonc` / `cvm_sl_mysql_lib`）。跨平台与版本合规见 §4/§5。

### 1.2 `WebUI.jsonc`（关键段）

```jsonc
{
  "project": {
    "name": "SLangWebUI",
    "desc": "WebUI GUI library module - namespace SLang.WebUI (browser-as-GUI, backed by webui_lib.dll / vendored webui.c, MIT)",
    "mainVersion": 0, "subVersion": 1,
    "buildVersion": 0, "buildSubVersion": 0
  },
  "source": { "root": "." },

  // FFI 导入：平铺 basename（同 Mysql）。cvm 装载即预载并注册静态绑定表，
  // @DllStaticImport("webui_lib", "webui_xxx_sl") 直调，绑定失败回退 SL 函数体。
  "dllImports": [
    { "path": "webui_lib.dll", "name": "webui_lib", "alias": "webui_lib", "static": "webui_lib" }
  ],

  // vmDlls：导出 SL 模块时，Front 用 MSBuild 编译下方 vcxproj，把 webui_lib.dll
  // 拷到与 SLangWebUI.module.json 同目录（out/export/SLangWebUI/）。
  // C 实现：SlangAllInOne\SLangCore\Lib\SLang\WebUI\cvm_webui_lib\cvm_webui.c
  // （内嵌 vendored webui.c，MIT；产出自包含，不依赖外部 webui.dll）。
  "vmDlls": [
    { "project": "cvm_webui_lib/cvm_webui_lib.vcxproj",
      "name": "webui_lib.dll", "configuration": "Debug", "platform": "x64" }
  ],

  "systemCalls": [],   // 全部能力走 @DllStaticImport 静态绑定，不下沉 cvm SystemMethodCall

  "compile": {
    "optimize": false, "target": "x64", "debug": true,
    "isUseForceSemiColonInLineEnd": true,
    "isForceUseClassKey": false, "isSupportDoublePlus": false,
    "requireSameNumericTypes": false
  },

  "compileFiles": {
    "files": [ { "path": "WebUI.sl", "group": "webui", "tag": "gui", "ignore": false, "priority": 0 } ]
  },

  "references": [
    { "path": "../../Core", "name": "Core" },      // Tuple/List/Array/string 等
    { "path": "../../Std",  "name": "Std"  }       // FFI.StaticLibrary / Memory 等
  ],

  "struct": [
    { "namespace": "SLang", "children": [
      { "class": "WebUI" },
      { "class": "WebUI.Window" }
    ]}
  ],

  "export": {
    "moduleName": "SLangWebUI",
    "outputDir": "..\\..\\..\\..\\out\\export",
    "versionMain": 1, "versionSub": 0, "versionPatch": 0,
    "includeMetadata": true,
    "debugText": { "outputDir": "", "code": true, "token": true, "node": true,
                   "file": true, "meta": true, "ir": true }
  }
}
```

> 注：`struct` 段登记 `WebUI` 与 `WebUI.Window` 两个顶级类型（SLang 要求类型必须是
> namespace 下的顶级类型，不能嵌套在类内，见 `MysqlClient.sl` 顶部注释）。

## 2. 原生库构建（`cvm_webui_lib`）

### 2.1 Windows（vcxproj）

- 工程：`Lib/SLang/WebUI/cvm_webui_lib/cvm_webui_lib.vcxproj`（与源码同目录，
  jsonc 里写相对路径 `cvm_webui_lib/cvm_webui_lib.vcxproj`；Mysql 同样与源码同目录，
  位于 `Lib/SLang/Mysql/cvm_sl_mysql_lib/`，jsonc 相对路径
  `cvm_sl_mysql_lib/cvm_sl_mysql_lib.vcxproj`）。
- 源文件：`cvm_webui.c` + vendored `webui.c`（一同编译进 dll）；头：`cvm_webui.h`、
  `webui.h`。
- 平台：`x64`（SLang FFI 仅 x64，见 `ffi.md` §9）。
- 配置：Release 也可；Debug 用于排查 cvm 自身 bug（见 `AGENTS.md` R20）。
- 不依赖外部 `webui.dll`——webui.c 内嵌编译，产物自包含。
- WebView2 形态（Windows）需目标机 `WebView2Loader.dll`；P1 默认浏览器模式不需要。

### 2.2 Linux / macOS（CMake，P5）

- `cvm_webui_lib/CMakeLists.txt`：`add_library(webui_lib SHARED cvm_webui.c webui.c)`，
  链接 pthread（`webui` 在 Unix 需 `-lpthread`）。
- 产物 `libwebui_lib.so` / `libwebui_lib.dylib`；
- `WebUI.jsonc` 的 `dllImports.path` 用平铺 basename `webui_lib.dll` 仅 Windows 语义；
  跨平台回退链（见 `ffi.md` FFI 回退：`pkg_dir/<平台>/basename`）由 cvm 处理，
  Linux 下实际解析为 `libwebui_lib.so`。需验证 cvm 在 Linux 下的扩展名回退逻辑
  （列为 P5 验收项）。

## 3. 装配与运行数据流（对标 Mysql）

```
WebUI.sl ──@DllStaticImport(CallFFIStatic 77)──> webui_lib.dll
            ──内嵌编译──────────────────────> webui.c（MIT，自包含）

导出：Front 编译 WebUI.sl → SLangWebUI.module.json（含 dllImports 段）
装载：cvm 读 module.json → 预载 webui_lib.dll → 注册 FFI 静态绑定表
运行：SLang 程序 new Window / bind / show / wait
```

- `vmDlls` 让 Front 在导出 SL 模块时自动编译并部署 `webui_lib.dll` 到
  `out/export/SLangWebUI/`，与 `dllImports` 别名指向的位置一致（同 Mysql 机制）。
- 运行期 `slang <project>` 一体化（编译→SLIR→VM 执行，见 `AGENTS.md`）即可直接跑 GUI 程序。

## 4. 版本与合规（R17 / R14 / R16 / R3）

- **R17 四端统一版本**：本模块**不另立版本号**，沿用仓内统一版本（当前 `0.0.38`）；
  `jsonc` 的 `export.versionMain/Sub/Patch` 仅模块语义版本（沿用 Mysql `1.0.0` 风格），
  不与仓内统一版本冲突。
- **R14 改动配文档**：本设计集为 P0 文档落点；实现后补 `WebUI.md`（库说明，对标
  `MysqlClient.md`）并同步 `SlangAllInOne/md/INDEX.md` 与 `md/lib/` 链接。
- **R16 UTF-8**：本目录新建文本文件统一 UTF-8。
- **R3 平台代码**：SLang 核心 `csimple_lang/src/vm/**` 不引入平台代码；平台差异由
  vendored `webui.c` 自身 `_WIN32/__linux__/__APPLE__` 分支承担，`cvm_webui_lib` 仅做
  扁平封装，自身不含平台分支（除线程局部缓冲宏等极少处）。
