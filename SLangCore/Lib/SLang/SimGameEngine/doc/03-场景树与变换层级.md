## 1. Scene【设计稿】

Scene 是树的根容器，负责持有根节点列表、按名查找与帧序遍历。拟定接口：

```sl
public class Scene
{
    public string name
    public Array<GameObject> roots()

    public GameObject createObject( string name )                  # 挂到根
    public GameObject createObject( string name, GameObject parent )
    public GameObject find( string path )                          # "Root/Child/Leaf"
    public Array<GameObject> findAllByTag( string tag )
    public Array<GameObject> findAllByLayer( int layer )
    public void destroy( GameObject go )
    public void updateTransforms()                                 # 脏节点自顶向下刷新
}
```

同一时刻允许多个 Scene 存在（如主场景 + 常驻 UI 场景），但只有被 `Application` 激活的 Scene 参与帧循环。场景切换时旧 Scene 根节点整体销毁，帧尾统一释放。

## 2. 父子层级

### 2.1 树规则

- 一个节点最多一个父节点；`parent = null` 表示根节点；
- 禁止把祖先挂到自己的子孙下（形成环），`setParent` 必须做环检测；
- 子节点按插入顺序排列，`getChild(index)` 按下标访问；
- 遍历顺序 = 深度优先、父先子后。整个引擎的 `awake/start/update/lateUpdate`、变换刷新、可见性收集都遵循这个顺序。

### 2.2 变换继承

每个 GameObject 自带一个 Transform（第 02 章硬规则）。Transform 提供双层状态：

| 层 | 含义 | 何时变化 |
|---|---|---|
| localPosition / localRotationZ / localScale | 相对父节点 | 脚本直接写 |
| worldPosition / worldRotationZ / worldScale | 树累乘结果 | 变换刷新阶段统一算 |

约束：

- 写入 local 值只标脏，不立即重算 world；同一帧多次写入只算一次；
- 刷新从根向子推进，父节点算完再算子节点；
- `setParent()` 默认保持 **local** 变换不变（世界位置会变）；需要保持世界位置时，先读旧 world，再反算新 local；
- 非均匀缩放 + 旋转的组合会产生剪切，本模块只支持 TRS（平移 / 旋转 / 缩放）分解，剪切不保留。

### 2.3 激活传播

```
activeInHierarchy(go) = go.activeSelf && activeInHierarchy(go.parent)
```

- 禁用父节点：整棵子树跳过更新与渲染，子节点 `activeSelf` 保持原值；
- 启用父节点：子树恢复各自原来的启用态；
- 组件级 `isEnabled` 与节点级激活是**两道独立开关**，任一关闭都不执行 `update()`。

## 3. Layer 与剔除协作

`layer` 是 0..31 的整数，与 Render 相机的 `cullMask` 按位对应：

- 节点挂到 layer N → 收集阶段置位 `1 << N`；
- 相机 `cullMask` 由当前 Camera 组件给出，调用 `pipe.setCamera(cullMask, l, r, b, t)` 下发；
- 位与为 0 的节点不进入可见候选，自然也不会产生 RenderObject；
- UI 节点建议单独占一个 layer，避免被 3D 相机重复收集（第 08 章）。

## 4. 空间工具【已落盘】

三个几何值类位于本模块根目录，使用 `Math` 库的 `Float32_2/3/4x4`。它们**不依赖**场景树，可在任何地方独立使用。

### 4.1 Bounds（`../Bounds.sl`）

轴对齐包围盒，用 `min` / `max` 两个 `Float32_3` 表示。

| 成员 | 签名 | 说明 |
|---|---|---|
| 字段 | `Float32_3 min`, `Float32_3 max` | 可直接读写 |
| 属性 | `Float32_3 center` | 中心点 |
| 属性 | `Float32_3 size` | `max - min` |
| 属性 | `Float32_3 extents` | 半尺寸 |
| 属性 | `bool isValid` | max 各分量均 ≥ min |
| 判定 | `bool contains(Float32_3 p)` | 含边界 |
| 判定 | `bool intersects(Bounds other)` | AABB 相交 |
| 扩展 | `void encapsulate(Float32_3 p)` / `void encapsulate(Bounds other)` | 原地扩展 |
| 扩展 | `Bounds expand(Float32 amount)` / `Bounds expand(Float32_3 amount)` | 返回新盒 |
| 查询 | `Float32_3 closestPoint(Float32_3 p)` | 盒内或边界上最近点 |
| 查询 | `Float32 distanceTo(Float32_3 p)` | 点在盒内返回 0 |
| 射线 | `bool intersectsRay(Ray ray)` | slab 算法 |
| 射线 | `Float32 intersectRayDistance(Ray ray)` | 进入距离，未命中返回 -1 |
| 工厂 | `static Bounds fromCenterSize(Float32_3 center, Float32_3 size)` | — |
| 工厂 | `static Bounds fromPoints(Array<Float32_3> points)` | 空数组返回无效盒 |
| 工厂 | `static get Bounds empty()` | 零盒 |

### 4.2 Plane（`../Plane.sl`）

平面方程 `dot(normal, p) + distance = 0`，构造时自动归一化法线并同步缩放 distance。

| 成员 | 签名 | 说明 |
|---|---|---|
| 字段 | `Float32_3 normal`, `Float32 distance` | — |
| 查询 | `Float32 distanceToPoint(Float32_3 p)` | 正 = 法线正侧 |
| 查询 | `bool getSide(Float32_3 p)` | 是否在正侧（含平面） |
| 查询 | `Float32_3 closestPointOnPlane(Float32_3 p)` | 最近点 |
| 射线 | `Float32 raycast(Ray ray)` | 转发 `ray.intersectPlane(this)` |
| 变换 | `Plane flip()` / `Plane translate(Float32 delta)` | 翻转法线 / 沿法线平移 |
| 工厂 | `static Plane fromNormalAndPoint(Float32_3 normal, Float32_3 point)` | — |
| 工厂 | `static Plane fromThreePoints(Float32_3 a, Float32_3 b, Float32_3 c)` | 右手定则；共线返回默认平面 |
| 工厂 | `static Plane ground(Float32 height)` | 地平面 `y = height` |

### 4.3 Ray（`../Ray.sl`）

`origin + direction`，构造时 direction 自动归一化（零向量回退 `Float32_3.forward()`）。

| 成员 | 签名 | 说明 |
|---|---|---|
| 字段 | `Float32_3 origin`, `Float32_3 direction` | 建议保持单位方向 |
| 查询 | `Float32_3 getPoint(Float32 distance)` | 沿射线取点 |
| 求交 | `Float32 intersectBounds(Bounds b)` / `bool intersectsBounds(Bounds b)` | 转发 Bounds 的 slab 算法 |
| 求交 | `Float32 intersectPlane(Plane p)` | 返回距离，平行或背向返回 -1 |
| 求交 | `Float32_3 intersectPlanePoint(Plane p)` | 交点，未命中返回 null |
| 变换 | `Ray transformBy(Float32_4x4 m)` | 点用 transformPoint，方向用 transformDirection 后归一化 |
| 工厂 | `static Ray fromTo(Float32_3 from, Float32_3 to)` | 方向从 from 指向 to |

### 4.4 组合示例：点击地面

```sl
import Math;

Plane ground = Plane.ground( 0.0f )
Ray ray = Ray( Float32_3( 0.0f, 10.0f, 0.0f ), Float32_3( 0.0f, -1.0f, 0.0f ) )
Float32 t = ray.intersectPlane( ground )
if t >= 0.0f
{
    Float32_3 hit = ray.getPoint( t )       # (0, 0, 0)
    Bounds area = Bounds.fromCenterSize( Float32_3.zero(), Float32_3( 10.0f, 0.0f, 10.0f ) )
    if area.contains( hit )
    {
        Console.println( "hit ground" )
    }
}
```

## 5. 场景收集与合批的衔接

变换刷新完成后，收集阶段对每个激活节点做三件事：

1. 检查 `activeInHierarchy` 与 layer 位（§3）；
2. 若节点挂了 Renderer / Camera / Light / UI 组件，把它的 world 变换与组件数据写入「可见候选」；
3. 用 Bounds 做粗粒度包围盒筛选（可选优化），再送入第 05 章的合批器。

注意：`Bounds.sl` 是**轴对齐**盒；节点旋转后需要用变换后的顶点重新 `fromPoints` 生成世界 AABB，不能直接把 local 盒的 min/max 加个位置了事。

## 6. 已知坑与注意

1. `intersectRayDistance` / `intersectPlane` 的「未命中」统一用 **-1** 表示，不是 0；命中点恰好在原点时 t = 0 也是合法命中。
2. `Plane` 构造函数会按法线长度同步缩放 distance；已有单位法线时直接传 distance 即可，不要把 distance 再除一次。
3. `Ray.intersectPlane` 对**背向**射线也返回 -1（分母为负时 t < 0），做双面拾取时先 `flip()` 再试一次。
4. `Bounds.fromPoints()` 空数组返回默认零盒而非无效盒的极端值；用 `isValid` 判断前请确认点集非空。
5. 【2026-11-16 落盘说明】世界矩阵采用「local 脏标记缓存 + world 读侧沿父链累乘」，读 `worldPosition` 永远拿到当前值（无上一帧陈旧问题）；`Scene.updateTransforms()` 保留为显式批量刷新/预热入口。
6. 【2026-11-16 落盘说明】Transform / Scene / GameObject / Application 已落盘（`SimEngineTest` 60 项全绿）；`worldToLocalMatrix` 用 TRS 解析逆（含缩放，非 inverseRigid 近似）。本章层级接口即实际 API；§4 三个几何类不变。
