# 17 — 固定形状库（Shape Library）

> 版本：v1（2026-11-17，P9；参考 Unity ProBuilder `ShapeGenerator` 形状集）
> 定位：一组**固定的参数化形状**（Cube/Plane/Sphere/Cylinder/Cone/Torus/Prism/Pipe/Arch/Stair/Sprite）的顶点/法线/UV/三角形生成。计算核心在 C99 原生库（专项约定：重计算一律进 `cvm_sim_engine_lib`，SL 侧只放类与接口），SL 侧经 `EngineFfi` 绑定 + `ShapeFactory` 门面消费。

---

## 1. 类与接口

| 类 | 文件 | 职责 |
|---|---|---|
| `ShapeTypes` | `shape/ShapeTypes.sl` | 形状号常量表（CUBE=0 .. STAIR=10，与 C 侧形状表逐项一致） |
| `ShapeMesh` | `shape/ShapeMesh.sl` | 网格数据容器（positions/normals/uvs 平铺 + triangles） |
| `ShapeFactory` | `shape/ShapeFactory.sl` | 工厂门面：通用入口 `build(type, params)` + 每形状便捷方法 |
| `EngineFfi` | `EngineFfi.sl` | C 绑定单点：`libShapeCounts` / `libShapeBuild` |

### C 导出（sle_engine.h / sle_engine.c）

| 符号 | 签名 | 语义 |
|---|---|---|
| `sle_shape_counts` | `(int32 type, const float* params, int32 paramCount, int32* out) -> int32` | out 填 `[vertCount, triCount]`；0 成功 / -1 形状号 / -2 参数 |
| `sle_shape_build` | `(int32 type, const float* params, int32 paramCount, float* dst, int32* tris) -> int32` | dst = `[pos 3V \| nrm 3V \| uv 2V]`（float），tris = 3T 个 int32；返回顶点数 / 负错误码（-4 = 内部计数漂移守卫） |

两段式调用：先 `counts` 拿 V/T 分配缓冲，再 `build` 填充（`ShapeFactory` 已封装全程）。

## 2. 形状表（参数序 = 便捷方法参数序）

全部形状：**中心在原点、Y 轴向上、右手系、从外侧看逆时针（CCW）绕序**；整型参数以 Float32 传入。

| type | 形状 | 参数 | 默认规模（测试锚点） |
|---|---|---|---|
| 0 | Cube | sx,sy,sz | V24 T12（6 面独立顶点 + 面法线） |
| 1 | Plane | width,height,cols,rows | XZ 平面网格，法线 +Y；V=(cols+1)(rows+1) T=2·cols·rows |
| 2 | Sprite | width,height | XY 单面片，法线 +Z；V4 T2 |
| 3 | Sphere | radius,segU,segV | 经纬球（segU>=3, segV>=2）；V=2+(segV-1)(segU+1) T=segU(2segV-2) |
| 4 | Cylinder | radius,height,segments,heightSegments | 含双端盖（各带 1 中心顶点）；V=(seg+1)(hSeg+1)+2(seg+2) T=2seg·hSeg+2seg |
| 5 | Cone | radius,height,segments | 含底盖；V=seg+3 T=2seg |
| 6 | Torus | radius,tube,segU,segV | 主圈绕 +Y；V=(segU+1)(segV+1) T=2segU·segV |
| 7 | Prism | sx,sy,sz | 三棱柱（XY 三角截面顶点朝上、沿 Z 拉伸）；V18 T8 |
| 8 | Pipe | radius,height,thickness,segments | 空心管（外壁/内壁 + 双环端盖）；V=6(seg+1) T=8seg；thickness < radius |
| 9 | Arch | angleDeg,radius,width,thickness,segments | 竖直拱带（XY 竖直弧、Z 向宽）；V=4(seg+1)；T=8seg+(angle<360 ? 4 : 0) |
| 10 | Stair | steps,width,stepHeight,depth | 直梯（闭合盒逐级沿 +Z 上升、整梯居中）；V=24·steps T=12·steps |

## 3. 使用用例

### 3.1 便捷方法 + 灌入引擎合批通道

```
import SimGameEngine;

ShapeMesh m = ShapeFactory.cube( 2.0f, 2.0f, 2.0f )
if m == null
{
    # 绑定失败/参数非法（libShapeCounts 兜底 -1 → null）
    ret
}
MeshRef meshRef = MeshRef.create( 0 )
m.applyTo( meshRef )          # 顶点进模型空间合批通道（hasVertexData 路径）
```

### 3.2 通用入口（动态选形状）

```
Int32 t = ShapeTypes.TORUS          # static 常量先赋局部变量再传（不作实参）
Array<Float32> p = Array<Float32>( 4 )
p[0] = 1.0f
p[1] = 0.3f
p[2] = 16.0f
p[3] = 8.0f
ShapeMesh m = ShapeFactory.build( t, p )
```

### 3.3 转 SLang.Mesh（消费方自理）

`ShapeMesh` 所在模块引用 SLangRender 为 slb 形态（不可声明跨模块局部变量），转 `SLang.Mesh` 由引用 `.module.json` 元数据的模块自理：

```
SLang.Mesh mesh = SLang.Mesh( m.getPositions(), m.getTriangles(), m.getNormals() )
```

### 3.4 逐顶点访问

```
int n = m.vertexCount()
int i = 0
while i < n
{
    Float32_3 v = m.getVertex( i )
    Float32_3 nm = m.getNormal( i )
    Float32_2 uv = m.getUv( i )
    i = i + 1
}
```

## 4. 使用技巧与已知边界

- **绑定失败判空**：`ShapeFactory.build` 返回 null 的三种情形——形状号非法（C 返回 -1）/ 参数非法（-2）/ FFI 兜底（libShapeCounts 绑定失败恒 -1）。`build` 内部 V/T 与写入计数不一致时 C 侧守卫返回 -4（防布局漂移静默出错网格）。
- **形状号常量不作实参**：`ShapeFactory.build(ShapeTypes.CUBE, ...)` 会触发 `MetaCoreCallNotSupportNotSupport`——先赋局部变量（`Int32 t = ShapeTypes.CUBE`）或用便捷方法（内部走字面量）。
- **绕序自检口径**：三角形几何法线与首顶点法线 dot > 0 = CCW 外向；dot ≈ 0（垂直）为共享顶点端面的正常形态（见下条）。测试判坏阈值为 dot < -1e-4。
- **共享顶点端面着色近似（v1 已知边界）**：Arch 的前/后盖与两端封口顶点与壁面环共享，法线为径向——端面光照着色是近似值（几何与绕序正确）；需要精确端面法线时由消费方对 `ShapeMesh` 复制端面顶点并覆写法线。Cylinder/Pipe 端盖已有独立 ±Y 法线环（无此问题）。
- **Sphere 为经纬球**（UV sphere，非 ProBuilder 的 icosphere）：极点各 1 顶点、UV 无接缝断裂；segU/segV 控制细分（默认建议 16/8 以上接近圆滑）。
- **Stair 为逐级闭合盒**：各级独立 6 面（V=24·steps），含被遮挡面——若需减面可由消费方做剔除合并；台阶沿 +Z 上升、整体包围盒中心在原点。
- **ProBuilder 未对齐项**：Door / Stair(弧形楼梯 CurvedStair) / Arch 的立柱柱脚形态未做（v1 形状集 = 11 种）；后续按需在 C 形状表追加 type 与 dims 即可（`sle_shape_dims` 为单一规模真源，build 与 counts 共用）。
- **新增形状流程**：C `sle_shape_dims`（规模）+ builder（写入）+ `sle_shape_build` 分派 + `sle_engine.h` 登记（漏登记 = dll 无符号 = FFI 静默兜底）+ `ShapeTypes` 常量 + `ShapeFactory` 便捷方法 + 测试锚点。
