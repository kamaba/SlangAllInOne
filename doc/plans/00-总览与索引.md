```

  P0 FFI 重构 ──┬──► P3 webview
  P7-T1 CI 搭建 └──► P6-B OpenBLAS 绑定（Tensora 性能急救）
  P1 若依重写（与 P0 并行主线）

阶段二（1~2 个季度）
  P1 完成 ──► 官网完善 + 性能对比数据
  P2 spm MVP ──► 若依拆包验证 ──► 官网 registry 期

阶段三（并行推进）
  P4 CPython 插件
  P5 AOT（RFC 定稿 ──► M1/M2/M3）

  P6 渲染引擎（bgfx/sokol）／ SLangQT ／ Tensora GPU

```

## 三条执行原则

1. **每个大项必须产出可对外展示的东西**（Demo / 对比数据 / 在线体验）；
2. **每次真实使用暴露的缺陷优先于新功能**（dogfooding 优先）；
3. **能借生态的不自研**（BLAS / webview / CPython / bgfx），自研火力集中在语言内核与工具链差异化。
