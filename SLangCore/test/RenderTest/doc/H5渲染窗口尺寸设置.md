# H5 渲染页 · 窗口尺寸（手机分辨率）设置

## 功能

RenderTest 的 WebGL 直渲页（`out/rt_webui/index.html`，由 `RenderTestWebUI.sl` 的 `buildPage()` 生成）在画布**外**的 HTML 工具栏里提供一个「渲染尺寸」下拉框。选中一个常用手机/平板分辨率后，H5 渲染窗口（canvas）**即时调整**到对应尺寸，无需刷新页面或重启窗口。

## 可用分辨率

| 档位 | 尺寸（宽×高） |
|------|------|
| Default | 640×360（缺省，与原行为一致） |
| Phone | 360×640 |
| iPhone SE | 375×667 |
| iPhone 12/13 | 390×844 |
| Android | 393×851 |
| Android | 412×915 |
| iPhone Max | 430×932 |
| Phone Landscape | 667×375 |
| Tablet | 768×1024 |
| HD | 1280×720 |

下拉框右侧的 `[WxH]` 标签实时显示当前画布尺寸。

## 使用方式

1. 编译并运行 RenderTest（`slang compile RenderTest.jsonc --format binary` → `slang run ...RenderTest.module.slb`），Phase W 会把最新页面写到 `out/rt_webui/index.html` 并由 WebUI 在浏览器打开。
2. 在顶部工具栏的下拉框选择分辨率，canvas 立即变为对应尺寸，场景按新尺寸重新布局（左右双相机分屏各占半宽）。
3. 切回 `Default 640x360` 即恢复原始默认尺寸。

## 实现要点 / 注意事项

- 尺寸选择控件是画布外的纯 HTML `<select>`，在 `buildPage()` 的 `#bar` 工具栏内生成；页面为纯 ASCII。
- 逻辑尺寸保存在 JS 变量 `CW/CH/HW`（缺省 640/360/320），`resizeCanvas(w,h)` 同时更新 `canvas.width/height` 与 `resspan` 标签；`onchange` 把 `"w,h"` 拆开后调用它。
- WebGL viewport 不写死：`render()` 左相机用 `gl.viewport(0,0,HW,CH)`、右相机用 `gl.viewport(HW,0,CW-HW,CH)`，push 推帧对比模式用 `gl.viewport(0,0,CW,CH)`，因此改尺寸后各视口同步铺满新画布。
- `resizeCanvas` 对尺寸做 [32,4096] 范围保护，非法值直接忽略。
- 刷新页面会回到缺省 640×360（选择只保留在当次页面会话中）。
