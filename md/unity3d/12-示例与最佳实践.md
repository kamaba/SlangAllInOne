## 1. 最小示例：HelloCube（SL 驱动旋转 + 热更改色）

### 1.1 SL 热更脚本（`MyHot.sl`）
```sl
// 绑定层暴露的 Unity API（见 05 §2.1 systemCall）
import Unity;                       // 声明 SystemUnity.* 可用

function main() {
    var go = Unity.Find("Cube");     // 经 host 回调找场景对象
    Unity.Log("sl hot-reload ready");
}

// 每帧由 SlangLifecycle.Update 调用（06 §1）
function tick(dt: double) {
    var t = Unity.GetTransform("Cube");
    t.Rotate(0, 60 * dt, 0);         // Vec3 编组（05 §3）
}

// 热更：改下面这行颜色，保存即生效（04 文件监视）
function color() {
    return Unity.Color(1, 0.4, 0.1); // 橙
}
```

### 1.2 Unity C# 桥接（示意，`SlangUnityBridge.cs`）
```csharp
// 装载：开发期零落盘（04 §2.2），真机读 StreamingAssets（09 §3）
int rc = SlangNative.cli_run_module_in_memory(jsonUtf8, baseDirUtf8,
    (int)(SlangMemFlag.NoBanner), IntPtr.Zero, 0);

// 每帧驱动（06 §1）
void Update() => SlangLifecycle.Tick(Time.deltaTime);

// host 回调：SL 调 Unity.Log（05 §4）
static void Host_UnityLog(IntPtr msgUtf8) => Debug.Log(Marshal.PtrToStringUTF8(msgUtf8));
```

### 1.3 热更演示
1. Play Mode 运行，Cube 旋转、Console 打印。
2. 改 `color()` 返回值为 `(0.2, 0.8, 1)`（蓝），保存。
3. `AssetPostprocessor` 触发重编译 → 文件监视 → 主线程重装载（`04` §3）。
4. **不重启 Play Mode**，Cube 变蓝，验证热更闭环。

## 3. 最佳实践

| 主题 | 建议 |
|------|------|
| 热更粒度 | 起步用「整模块替换」（`04` §4.1），不重建 Unity 对象 |
| 线程 | VM 调用限定**主线程**（`03` §3、`06` §2） |
| JIT | 统一关 `SL_JIT=0`，避免 Editor/真机错配（`08`） |
| 编码 | 全程 UTF-8（R16），中文模块名/字符串无乱码 |
| 高频逻辑 | 下沉 Unity C#/C++，SL 做编排（`08` §5） |
| 版本 | 四端版本同步 +1（R17）；slb 带 uuid（`04` §5） |
| 排障 | `info`/`plugin list` 核装载（`07` §4）；`SL_VM_LOG=on` 落盘 |
| 调试 | Editor 接 SLDP，断点单步（`07` §1） |

## 4. 常见坑

| 坑 | 现象 | 解法 |
|----|------|------|
| 文件事件跨线程 | 重装载崩（非主线程调 Unity API） | `UnitySynchronizationContext` 派发（`06` §2） |
| Domain Reload | 进 Play Mode 后 VM 句柄失效 | 钩子重建桥接（`06` §3） |
| slb 陈旧 | 热更不生效 | 先写 slb 且 mtime 新 / `--force-json` 过渡（`04` §6） |
| 裸指针悬垂 | 跨帧访问已销毁 Unity 对象崩溃 | handle 表（`05` §6） |
| iOS JIT 崩 | Archive 失败 / 运行时崩 | `VM_JIT_ENABLE=OFF` + `SL_JIT=0`（`08`） |
| Android StreamingAssets | 直接读 apk 内 slb 失败 | 先拷 `persistentDataPath`（`09` §3） |
