## 4. 维护约定

1. **路径与行号会漂移**：本文中的 `文件:行号` 是整理时的锚点，源码变动后以实际源码为准；结构性结论（阶段顺序、调用链）优先于具体行号。
2. **权威源优先级**：路径/工程布局 → 根 `PROJECTS.md`；发布包布局 → `md/project/package-layout.md §七`；构建命令 → 根 `AGENTS.md §5`；用户向语义 → `md/INDEX.md`。
3. **新增子系统**：在 `doc/system/` 增一篇项目文档并同步本索引（清单 + 主题速查），保持 5~10 篇规模。
4. **面向读者的边界**：本目录属系统/设计文档，可含源码路径、类名、函数名；面向 SL 使用者的文档（语法/库/工程配置）仍只写规则、用例、方法与注意事项，见根 `AGENTS.md` 的文档约定。
