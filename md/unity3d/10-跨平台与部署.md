# 10 · 跨平台与部署

> 各 Unity 目标平台的 C VM 原生插件部署清单，与原生插件 `.meta` 设置。
> 平台目录对齐 `lib\{windows,linux,macos,ios,android}`（`PLUGIN_SYSTEM_DESIGN.md`，见 `02` §2）。

---

## 1. 平台部署清单

| 平台 | 插件形态 | 关键设置 | 备注 |
|------|----------|----------|------|
| **Windows** | `csimple_lang.dll`（x86_64） | `Platform=Windows`, `CPU=x86_64` | 复用 `vm_lib` vcxproj（`02` §3.2）；R6 登记 |
| **macOS** | `libcsimple_lang.dylib` / `.bundle` | `Platform=OSX`, `CPU=x86_64/Apple Silicon` | 注意通用二进制/架构匹配 |
| **Linux** | `libcsimple_lang.so` | `Platform=Linux`, `CPU=x86_64` | Standalone Linux 服务端可用 |
| **iOS** | 静态库 `libcsimple_lang.a` + 源 | `Platform=iOS`, 加入 Xcode 工程 | **必须静态库 + 关 JIT**（`08`）；`VM_JIT_ENABLE=OFF` |
| **Android** | `libcsimple_lang.so` per ABI | `Platform=Android`, `ABI=arm64-v8a/armeabi-v7a/x86_64` | NDK 编；JIT OFF（arm64 后端 P5） |
| **WebGL** | `csimple_lang.wasm` + js | `Platform=WebGL` | 复用 `csimple_lang/md/WASM_BUILD.md` |

---

## 2. Unity 原生插件 .meta（关键字段）

| 设置 | 推荐值 | 说明 |
|------|--------|------|
| `Is Preloaded` | false | 按需 `DllImport` |
| `Platform` | 按上表勾选 | 未勾选平台不拷贝该文件 |
| `CPU` | 与目标 ABI 一致 | x86_64 / arm64 / 通用 |
| `OS` | 对应系统 | |
| iOS `Add to Embedded Binaries` | 视 Unity 版本 | 静态库通常不需要 |
| WebGL `Include in WebGL` | true | wasm + js 配对 |

> 直接复用 `PLUGIN_SYSTEM_DESIGN.md` 的 `package\{平台}\` 打包惯例导出，再用脚本生成对应 `.meta`，避免手工逐一设置。

---

## 3. 符号与体积

- Release 构建剥离符号（`csimple_lang/md/cli.md` 版本/构建信息）；iOS 注意 `bitcode`（新版 Xcode 已弃用，按 Unity 默认）。
- C VM 体量小（C99 紧凑实现），对首包影响有限；若担忧，可只把**热更用到的引用库**随包，主逻辑远程下发（`09` §4）。
- 关联 DLL（如 `sqlite3.dll` 等 FFI 依赖）按 `lib\<平台>\` 解析（`cli.md` 应用载荷模式 `sl_preload_associated_dlls`），随插件一并部署。

---

## 4. 版本目录与四端统一（R17）

- 插件产物按 `SLVM_VERSION_DIR`（`0.0.59`）版本目录落盘，与 Front / C VM / AllInOne / VSCode 四端同步 +1（`AGENTS.md` R17）。
- Unity 插件包本身也应有版本号（与 `package.json` 风格一致），随全仓演进。

## 5. 部署验证矩阵

| 平台 | 验证点 |
|------|--------|
| Win Standalone | `DllImport` 加载 + 跑 SL 模块 |
| Mac Standalone | 架构（Intel/Apple Silicon）匹配 |
| iOS 真机 | Archive 通过 + 关 JIT + 运行 SL |
| Android 真机 | `arm64-v8a` 加载 + 解释执行 |
| WebGL | wasm 在浏览器跑通 |
| Linux 服务端 | 无头跑 SL 逻辑 |
