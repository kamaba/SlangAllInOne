# 18 — 统一时间同步（Unified Time Sync）

> 版本：v1.1（2026-11-18）
> 定位：**一个贯穿渲染 / 音频 / 视频 / 游戏逻辑 / 物理的统一时间源**。引擎层单点推进（`TimeService`），全模块只读（`EngineTime` static 快照），域时钟挂接音频/视频播放头对齐。底层高精度单调钟 = C99 原生库（`sle_time_now_us`，QueryPerformanceCounter / clock_gettime，doc/09 §1）。
> v1.1 补齐「贯穿」闭环：渲染帧默认读引擎时间、音频播放头自动上报、视频域时钟门面、帧尾统一收口；并修正域偏移方向使 snap 后域时刻真正等于播放头。

---

## 1. 模型总览

```
宿主（QT QTimer / 无头 while）
    │  app.tick(-1)                ← -1 = 引擎自动实测帧间隔（推荐）
    ▼
TimeService.advanceFrame          ← 真实流逝 → 裁剪(maxDeltaTime) → 暂停 → timeScale
    ├── deltaTime / unscaledDeltaTime / smoothDeltaTime / elapsedTime / frameCount
    ├── 固定步长累加器 → pendingFixedSteps（物理/碰撞/稳定逻辑用）
    ├── 域时钟表（offset 微秒）：render / physics / logic / audio / video
    ├── EngineTime static 快照写入（全模块只读单点）
    └── 帧尾 syncExternalClocks：音频/视频播放头 → 域偏移（渐变/对齐）
```

时间读数流向（每帧 tick 内自动完成）：

| 消费方 | 读什么 | 时机 |
|---|---|---|
| 游戏逻辑（update/lateUpdate） | `EngineTime.deltaTime`（scaled） | tick 步骤 4 |
| 物理/碰撞（fixedUpdate ×N） | `EngineTime.fixedDeltaTime`（固定步长，不受 timeScale 影响——步长恒定，步数随 scaled dt 变化） | tick 步骤 3 |
| 渲染（插值/提交） | `EngineTime.fixedAlpha`（0..1，上一固定步状态↔当前状态插值系数）+ `EngineTime.frameCount`；`RenderSystem.frame(-1, dst)` 直接消费 `EngineTime.elapsedTime` | tick 步骤 7 更新，渲染提交段读 |
| 音频 | `EngineTime.audioNowUs()`（域时钟）；`Application.audioSystem` 挂上后每帧自动上报播放头 | tick 帧尾统一收口 |
| 视频 | `EngineTime.videoNowUs()`（域时钟）；`VideoClock.reportHeadUs/sec` 上报播放头 | tick 帧尾统一收口 |

**同步语义**：全模块共享同一个 C 单调钟基准（微秒 Int64）；域时钟 = 主钟 + 每域偏移。逻辑/物理/渲染默认与主钟同相（offset=0）；音频/视频由后端把「播放头」上报进来，帧尾统一折算偏移（snap 一步到位 / nudge 渐变防爆音）。对齐后域时钟等于播放头。

## 2. 类与接口（【已落盘】）

| 类 | 文件 | 职责 |
|---|---|---|
| `TimeService` | `time/TimeService.sl` | 时间推进状态机：advanceFrame / 固定步长累加器 / 域时钟表 |
| `EngineTime` | `time/EngineTime.sl` | static 快照门面（只读）+ 域时钟便捷查询 |
| `Application.time` | `Application.sl` | 服务实例（init 创建）；tick 全链路自动接入 |
| `EngineClock` | `EngineClock.sl` | C 单调钟封装（nowUs/mark/timer，doc/09 §1，原有） |
| `VideoClock` | `time/VideoClock.sl` | 视频域（5）播放头上报门面（秒/微秒、drift、clear） |
| `AudioSystem.syncClock/snapClock` | `system/AudioSystem.sl` | 当前音源播放头（秒）上报音频域（4） |

### 2.1 TimeService（推进侧）

| 方法 | 语义 |
|---|---|
| `advanceFrame(Float32 rawDt)` | 每帧一次。rawDt 秒；**< 0 = 用 C 单调钟自动实测**（推荐宿主形态；首帧 0）。产出全套读数 + 写 EngineTime 快照 |
| `syncConfig(paused, timeScale, fixedDt, maxDeltaTime, maxFixedSteps)` | 配置同步（Application 每帧灌入旧接口字段，真源不迁移） |
| `pendingFixedSteps` / `consumeFixedStep()` | 本帧待跑固定步数 / 每步消费一次 |
| `updateFixedAlpha()` | 帧尾插值系数 = 剩余累加 / fixedDt（0..1） |
| `resetAccumulators()` | loadScene / shutdown 重置累加器（不清运行时长与帧号） |

域时钟（域号 0..5 = master/render/physics/logic/audio/video，越界钳到 master）：

| 方法 | 语义 |
|---|---|
| `domainNowUs(domain)` | 域时刻（微秒）= C 单调钟 + 域偏移 |
| `domainDeltaUs(domain)` | 域帧间差（首调记基线返回 0） |
| `setDomainOffset(domain, offsetUs)` | 直设偏移 |
| `snapDomain(domain, sourceNowUs)` | 一步对齐：offset = 外部源播放头 − 主钟（seek 后用；对齐后域时刻 = 播放头） |
| `nudgeDomain(domain, targetOffsetUs)` | 渐变对齐：每次最多移动 `maxNudgeUs`（默认 2000us，防音频爆音）；消漂移目标 = 当前offset − drift |
| `domainDriftUs(domain, sourceNowUs)` | 漂移 = 域时刻 − 源 = 主钟 + 偏移 − 源（> 0 = 域超前，需减小偏移） |

外部播放头帧尾收口（v1.1）：

| 方法 | 语义 |
|---|---|
| `reportAudioHead/reportVideoHead(headUs, snapNow)` | 后端只上报播放头，不直接改偏移；`snapNow=true` 用于 seek/换曲 |
| `syncExternalClocks()` | Application.tick 帧尾调用；统一折算两域偏移（渐变/一步对齐），记 `lastAudioDriftUs` / `lastVideoDriftUs` 与同步次数 |
| `clearExternalHeads()` | 停止上报（如音源释放、视频关闭） |

### 2.2 EngineTime（读侧，static 快照）

| 字段/方法 | 语义 |
|---|---|
| `deltaTime` / `unscaledDeltaTime` | 本帧推进量（秒；scaled / 原始） |
| `smoothDeltaTime` | EMA 平滑 dt（0.9/0.1，相机抖动抑制用） |
| `timeScale` / `paused` | 本帧生效配置 |
| `fixedDeltaTime` / `fixedAlpha` | 固定步长 / 固定步插值系数（渲染侧用） |
| `elapsedTime` / `unscaledElapsedTime` | 累计运行时长（秒；scaled / 原始） |
| `frameCount` | 帧号（Int64，从 1 起） |
| `renderNowUs()` / `physicsNowUs()` / `logicNowUs()` / `audioNowUs()` / `videoNowUs()` | 域时钟便捷查询（每域一个方法——static 常量不作实参，见 doc/10 §6） |
| `domainNowUs(domain)` | 通用域查询（domain 为局部变量时用） |

## 3. 使用用例

### 3.1 宿主主循环（推荐：自动实测）

```
import SimGameEngine;

Application app = Application()
app.init()
app.fixedDt = 1.0f / 60.0f
while running
{
    app.tick( 0.0f - 1.0f )     # -1 = 引擎自动实测帧间隔
    renderFrame( EngineTime.fixedAlpha )
}
```

QT 宿主：QTimer 回调里 `app.tick(-1)`（旧形态 `app.tick(0.016f)` 仍兼容——但那是「假定 16ms」而非真实流逝）。

### 3.2 脚本内读时间

```
public class Spinner extends Behaviour
{
    override void update()
    {
        Float32 dt = EngineTime.deltaTime
        Int32 fc = EngineTime.frameCount
        # ... 用 dt 推进
    }
    override void fixedUpdate()
    {
        # 物理稳定逻辑：步长恒定 = EngineTime.fixedDeltaTime
    }
}
```

### 3.3 渲染侧固定步插值（物理/渲染解耦另一半）

```
# 渲染提交前：上一固定步状态 与 当前状态 间插值
Float32 a = EngineTime.fixedAlpha
# pos = lerp( prevPos, currPos, a ) —— 状态缓存由消费方自理
```

### 3.4 音频播放头对齐（自动，推荐）

```
Application app = Application()
app.audioSystem = AudioSystem()      # 挂上后每帧自动读当前音源播放头
app.audioSystem.init()
app.audioSystem.playSource( bgm )
app.tick( -1.0f )                    # 帧尾自动 reportAudioHead + syncExternalClocks
Int64 t = EngineTime.audioNowUs()    # 与播放头对齐的音频时间
```

手动上报（后端不在 AudioSystem 管理内时）：

```
app.time.reportAudioHead( headUs, false )   # 正常播放：渐变
app.time.reportAudioHead( headUs, true )    # seek/换曲：一步对齐
```

### 3.5 视频播放头上报

```
VideoClock vc = app.videoClock             # init 自动创建并绑定
vc.reportHeadSec( player.time, false )     # 秒 → 微秒，帧尾统一收口
# seek 后：
vc.reportHeadUs( player.positionUs, true )
Int64 now = vc.nowUs()                     # 对齐后的视频域时刻
Int64 drift = vc.driftUs()                 # > 0 = 域超前播放头
```

### 3.6 渲染读统一时间

```
RenderSystem rs = RenderSystem()
rs.frame( -1.0f, pixels )       # 负数 = 消费 EngineTime.elapsedTime（推荐）
rs.frame( 1.25f, pixels )       # 正数 = 旧显式时间兼容（动画回放/截图定帧）
```

## 4. 使用技巧与注意事项

- **推荐 tick(-1)**：宿主传固定 16ms 是「猜的时间」，与真实帧率漂移；自动实测以 C 单调钟为准（`sle_time_now_us`），切后台大间隔由 `maxDeltaTime` 裁剪。
- **timeScale 只缩放 dt，不缩放 fixedDt**：固定步长恒定（物理稳定），timeScale 变化表现为「每帧固定步数变化」；`elapsedTime`（scaled）随之慢放，`unscaledElapsedTime` 恒走真实时间。
- **暂停语义**：scaled dt=0（update/fixedUpdate 不推进、elapsedTime 停），unscaledDeltaTime/unscaledElapsedTime 照走（UI 动效/网络时钟可用）。
- **fixedAlpha 在帧尾更新**（tick 步骤 7）：渲染提交段读到的即本帧插值系数；精确整除帧（无余量）alpha=0。
- **域号别用 static 常量作实参**：`domainNowUs(EngineTime.DOMAIN_AUDIO)` 会触发 `MetaCoreCallNotSupportNotSupport`——用每域便捷方法（`audioNowUs()`）或先赋局部变量。
- **音频/视频 nudge 而非 snap**（正常播放期间）：offset 突变 = 播放头跳变（爆音/掉帧）；只有 seek/重置用 snap。渐变速率 `maxNudgeUs` 可调（默认 2000us/次，每帧一次 ≈ 每秒最多 120ms 修正）。
- **域偏移符号（v1.1 修正）**：`offset = 播放头 − 主钟`，域时刻 = 主钟 + offset = 播放头；drift = 域时刻 − 播放头（>0 超前，消漂移目标 = 当前offset − drift）。旧版 `snapDomain` 方向相反，v1.1 已改正——若外部代码自己算过 offset，需同步改号。
- **帧尾单点收口**：外部后端只调 `report*Head`，不要自己写 `setDomainOffset/nudgeDomain`；`syncExternalClocks` 每帧一次统一折算，避免多处改 offset 打架。`Application.audioSystem` 挂上即自动上报，无需宿主重复调用。
- **v1.1 边界**：域时钟是「主钟 + 偏移」模型——多线程原生渲染线程/音频线程不经 SL 读 C 单调钟即可获得同基准时间（`sle_time_now_us` 进程内一致）；引擎不直连音视频设备，真实播放头由后端上报（视频侧当前只有域时钟门面，无解码后端）。Int64 微秒域时钟无浮点漂移；Float32 秒级累计（elapsedTime）长时间运行有末位噪声，关键时长用 `EngineClock.nowUs()` 差分。
