## 1. 现状边界（先说清楚能用什么）

| 能力 | Render 侧现状 | 本模块可用路径 |
|---|---|---|
| 环境光强度 | `pipe.setAmbient(f)` 已落盘 | 直接调用（第 06 章灯光之外的基础环境项） |
| 环境查询 | `RenderEnvironment`（Phase ENV）已落盘 | 查询后端 / 统计 / 环境信息 |
| 天空盒 shader 源码 | HlslLibrary 内置 Skybox 源码，但首行 `#include Common` 是非法 HLSL（Render/doc/03 §4.x 记录的 bug） | 暂不能直接用 |
| SkyboxPass | Pass 清单里有设计（全屏三角 + cubemap，改走 fullscreen VS），**13 阶段正式阶段表里没有独立 skybox 阶段** | 等 Render 打通；或走 §3 过渡方案 |
| 雾效 | 无内置 Pass | shader 内实现，或由第 14 章 Volume 的 Fog 参数驱动（后者未落盘） |

结论：**`setAmbient` 现在就能用；真正的 cubemap 天空盒尚未接通**。写场景时不要把天空盒当作现成能力。

## 2. 天空盒组件【背景层已落盘 2026-11-16（渐变天空）；cubemap 组件设计稿】

### 2.0 渐变天空背景【已落盘 v0.1（C 管线层）】

v0.1 先落「背景层」：每相机清屏（COLOR 位）之后画一个全屏渐变 quad（顶→底线性插值，无深度写入），场景物体随后正常覆盖——`RenderSystem` 两方法转发到 SLang.RenderPipeline → C 管线 `slr_pipeline_set_sky_top/bottom/on`：

```sl
# RenderSystem（system/ 层）：
render.setSky( Float32_3( 0.1f, 0.3f, 0.9f ),      # 顶色 RGB 0..1
               Float32_3( 0.9f, 0.6f, 0.1f ) )     # 底色
render.setSkyEnabled( true )                       # 默认关；false 回到纯清屏色
```

实现与帧序（C 侧）：`SLR_PROG_SKY` 内嵌 GLSL program（`mix(uBottom, uTop, vUv.y)`，GL/GLES 后端实现、D3D11/VK vtable 槽为 NULL 判空跳过）；生效点在 `stage_render_shader_chunks` 的 `camera_begin` 之后、`set_state(0)` 之前——**不是独立 13 阶段**，不进 runStages 阶段表。验证：`SimSystemsTest` S6b~S6f（160×160 离屏出帧，顶部偏蓝/底部偏绿/上下不同三重像素断言）。

已实证坑（接 C 库时）：

- **C 导出必须在 `vm_sl_render.h` 声明表登记**（`SLR_API` 声明继承 dllexport）——只在 .c 定义不声明 = dll 无符号 = FFI 静默返回 false；
- **SL 侧 `DllStaticImport` 参数数上限实证 7 参失败**（5 参 set_clear_color 先例封顶）——多参数拆多个 4~5 参导出（set_sky_top / set_sky_bottom 分体）；
- `tr` 保留字第 4 次踩（doc/10 §6）；像素断言阈值放宽（GPU 输出 0.6→149 而非 153）。

### 2.1 cubemap 天空盒【设计稿】

```sl
public class Skybox extends Component
{
    public Texture cubemap             # 六面贴图（需 SLangImage + cubemap 上传链路）
    public Float32 intensity = 1.0f
    public Float32 rotationY = 0.0f
    public bool    followCamera = true # 每帧把节点位置对齐到主相机
    public bool    fogEnabled = false
    public Float32 fogDensity = 0.01f
}
```

约定：

- 一个激活 Scene 最多一个生效的 Skybox；多个时按挂载节点在树中的顺序取第一个；
- `followCamera = true` 时，节点 Transform 每帧在 `lateUpdate` 对齐相机位置（第 09 章帧序第 5 步），保证天空盒永远在无穷远；
- 天空盒不参与碰撞（第 11 章）与拾取（第 03 章）；
- 天空盒不受灯光影响（第 06 章），只受自身 intensity 与后处理影响。

cubemap 全链路缺口（2026-11-16 侦察定案，项目级工作量）：RHI `texture_create` 无 dimension/6 面上传（GL/GLES/D3D11/VK 四后端）；`sl_texture.c` 注册表无面数契约；描述符表无 TextureCube 采样槽；gen 头无 cube GLSL/DXBC 变体；`GpuTexture` 的 `Render.createTexture/uploadTexture` 外部函数无 sl_render_lib 落地；HDR/六面文件解码（WIC 仅 2D）；「SL 字符串 shader → GL 后端」编译通道不存在（GL shader 全为内嵌固化源）。HlslLibrary.skyboxShader() 源码已就绪（include 行已修），待上述通道打通后接入。

```sl
public class Skybox extends Component
{

    public Float32 intensity = 1.0f
    public Float32 rotationY = 0.0f

    public Float32 fogDensity = 0.01f
}
```

约定：

- 一个激活 Scene 最多一个生效的 Skybox；多个时按挂载节点在树中的顺序取第一个；

- 天空盒不参与碰撞（第 11 章）与拾取（第 03 章）；
- 天空盒不受灯光影响（第 06 章），只受自身 intensity 与后处理影响。

## 3. 过渡方案：用普通 RenderObject 画天空

在 Render 打通 SkyboxPass 之前，可以用已有门面拼一个可用版本：

```
1. 建一个专用 GameObject "Sky"，挂 MESH_CUSTOM 立方体（第 04 章 uploadMesh）
2. 材质绑定 cubemap 贴图（Texture.load + Material.setTexture）
3. 该 RenderObject 的 renderQueue 设为极小值（如 0），保证最先绘制
4. followCamera：lateUpdate 中把 Sky 节点位置设为主相机位置
5. 后续物体正常覆盖它（深度测试由 shader 负责）
```

限制与注意：

- 若 shader 不写深度 / 不开背面剔除，立方体可能挡住后续物体；当前 RenderObject 门面没有独立的 depth-write 开关，需在 shader 里处理，或扩展门面（设计稿）；
- 这是「假天空盒」：视差随相机移动会有轻微偏差，且无法做真实的无穷远采样；
- 相机切换后要重新对齐 Sky 节点（多相机 depth 列表，第 06 章）。

## 4. 环境光与雾

### 4.1 环境光【已落盘】

```sl
pipe.setAmbient( 0.35f )               # 全局环境强度，所有材质共享
```

它与灯光槽（第 06 章 `Light.applyTo`）的分工：

| 项 | 作用范围 | 可否逐物体 |
|---|---|---|
| `setAmbient(f)` | 全局基础亮度 | 否 |
| Light 槽 | 方向 / 点 / 聚光 | 否（全局槽） |
| Material 自发光 / 参数 | 单个材质 | 是（共享材质则一起变） |
| Volume 的 ColorAdjustments | 后处理级 | 按 Volume 影响范围（第 14 章，未落盘） |

### 4.2 雾效【设计稿】

两种实现路径：

1. **shader 内雾**：按世界距离混合雾色，优点是不额外 Pass，缺点是每种 shader 都要改；
2. **Volume Fog**： fogColor / fogDensity / start / end 作为 Volume 参数，后处理阶段统一处理（第 14 章，Render P2 未开始）。

v0.1 建议先用路径 1 在特定材质上做局部雾；全局雾等 Volume 参数栈落地。

## 5. 与 Volume / 后处理的关系

```
Skybox（背景色 / cubemap）
   ↓ 场景物体绘制（环境光 + 灯光）
   ↓ 13 阶段第 11 步 postProcess（亮度 / 饱和度 / 暗角，已落盘）
   ↓ Volume 参数栈（第 14 章，当前未落盘）
   ↓ 第 12 步 integrateLayers → 输出
```

天空盒是**场景内容**，会一同进入后处理；如果只想让天空更亮而不影响前景，应调 Skybox.intensity，而不是调全局 brightness。

## 7. 已知坑与注意

1. **`Texture.load` 需要 `SLangImage` 模块 + `import SLangImage;`**；缺依赖时贴图加载失败，天空变纯色。
2. **天空盒 shader 源码当前有非法 `#include Common`**（Render/doc/03 记录），不要直接拿 HlslLibrary 里的 Skybox 源码编译，会报错。
3. **13 阶段没有独立 skybox 阶段**：`runStages` 逐阶段调试时找不到它，属预期，不是配置漏了。
4. **`setAmbient` 是全局值**：在 `update()` 里反复改会影响所有材质，且不同相机无法各自设置（Volume 参数栈落地后才能按区域覆盖）。
5. **followCamera 要在 lateUpdate 做**：放在 `update()` 会被相机自身的跟随逻辑覆盖，导致天空盒滞后一帧。
6. **后端切换后 cubemap 与材质句柄失效**：跟第 04 章其它资源一样，必须全量重建。
