# 示例用例

> 本文给出 SLang + WebUI 的端到端用法示例，覆盖主要能力。所有示例基于 `03-SL层API设计`
> 的 `SLang.WebUI` API。用例集落点建议：`SlangAllInOne/SLangCore/test/Other/WebUITest/`
> （同 `MysqlTest` / `ServerTest` 的位置约定）。

---

## 1. Hello World（最小桌面 GUI）

```sl
import SLangWebUI;

public class App
{
    static void onGreet( Int64 e )
    {
        string who = SLang.WebUI.getArgString( e, 0 )
        SLang.WebUI.returnString( e, "Hello, " + who + " from SLang!" )
    }

    static void main()
    {
        SLang.WebUI.init()

        SLang.WebUI.Window win = new SLang.WebUI.Window()
        win.setSize( 480, 320 )
        win.bindEvent( "greet", SLang.WebUI.makeCallback( "onGreet" ) )

        win.show( "<html><body style='font:16px sans-serif;padding:20px'>" +
                  "<h3>SLang WebUI</h3>" +
                  "<input id='name' value='world'>" +
                  "<button onclick=\"greet(document.getElementById('name').value)\">Greet</button>" +
                  "<div id='out'></div>" +
                  "<script src='webui.js'></script></body></html>" )

        SLang.WebUI.wait()       # 阻塞至窗口关闭
        SLang.WebUI.clean()
    }
}
```

## 2. 按钮点击 + 多参数返回

```sl
public class Calc
{
    # JS: add(3, 4) -> SLang 返回 7
    static void onAdd( Int64 e )
    {
        Int64 a = SLang.WebUI.getArgInt( e, 0 )
        Int64 b = SLang.WebUI.getArgInt( e, 1 )
        SLang.WebUI.returnInt( e, a + b )
    }

    static void main()
    {
        SLang.WebUI.init()
        SLang.WebUI.Window win = new SLang.WebUI.Window()
        win.bindEvent( "add", SLang.WebUI.makeCallback( "onAdd" ) )
        win.show( "<html><body>" +
                  "<button onclick=\"document.title = add(3,4)\">3+4</button>" +
                  "<script src='webui.js'></script></body></html>" )
        SLang.WebUI.wait()
        SLang.WebUI.clean()
    }
}
```

> `returnInt` 把结果回传 JS，JS 侧 `add(...)` 的 Promise/返回值即可拿到。

## 3. 多窗口

```sl
public class MultiWin
{
    static void openChild( Int64 e )
    {
        SLang.WebUI.Window child = new SLang.WebUI.Window()
        child.setSize( 320, 200 )
        child.show( "<html><body><h4>Child</h4><script src='webui.js'></script></body></html>" )
    }

    static void main()
    {
        SLang.WebUI.init()
        SLang.WebUI.Window main = new SLang.WebUI.Window()
        main.bindEvent( "openChild", SLang.WebUI.makeCallback( "openChild" ) )
        main.show( "<html><body><button onclick='openChild()'>Open Child</button>" +
                   "<script src='webui.js'></script></body></html>" )
        SLang.WebUI.wait()       # 主窗 + 子窗都关才返回
        SLang.WebUI.clean()
    }
}
```

> `webui_wait()` 等待**所有**窗口关闭；每个 `Window` 独立窗口号。

## 4. 异步响应（长任务）

webui 支持 `asynchronous_response` 配置 + `webui_return_*`，处理函数在异步完成后返回。
SLang 侧可在回调里启动任务、稍后回写：

```sl
public class AsyncDemo
{
    static void onSlow( Int64 e )
    {
        # 模拟耗时：立即返回占位，后台计算后回写
        # （P1 默认 event_blocking=true 串行；真异步需 multi_client/线程安全，见 02 §4.2）
        string r = SLang.WebUI.script( e_as_window, "/* 后台计算 */ return 42;", 5 )
        SLang.WebUI.returnString( e, "result=" + r )
    }
}
```

> 注意：P1 默认串行模式，`webui_return_*` 应在**同一回调调用栈内**完成（同步返回）。
> 真正脱离调用栈的异步需后续 VM 线程安全改造（见 `07`）。

## 5. Kiosk / 全屏 + 隐藏

```sl
SLang.WebUI.Window win = new SLang.WebUI.Window()
win.setKiosk( true )        # 全屏 kiosk
win.setHide( false )
win.show( "<html><body>Kiosk Mode<script src='webui.js'></script></body></html>" )
SLang.WebUI.wait()
```

---

## 6. 执行 JS 并取回返回值

```sl
# 单向执行
win.runScript( "console.log('from SLang')" )

# 取回返回值（webui_script 封装 -> string）
string r = win.script( "return 6 * 7;", 5 )   # "42"
Console.println( "JS says: " + r )
```

## 7. 本地文件 / 文件夹模式（前端资源）

```sl
SLang.WebUI.Window win = new SLang.WebUI.Window()
# 设置 web 根目录，show 传相对文件
SLang.WebUI.libSetRootFolder( win.handle, "C:/myapp/www" )   # 经 _sl 封装
win.show( "index.html" )       # 走根目录
SLang.WebUI.wait()
```

> 也可用 `webui_start_server` 只起服务返回 URL（不弹窗），配合外部浏览器调试。
